Installation

Get up and running

  1. Open the GitHub Releases page and download the latest Windows 64-bit ZIP package.
  2. Extract the ZIP archive to a folder where you want to keep the application.
  3. Open the extracted folder and run the Ape Escape Recompiled launcher executable.
  4. In the launcher, select your own Ape Escape disc image. A CUE file with its matching BIN track is recommended; CHD is also supported.
  5. Review the controller, display, audio, and optional mod settings, then start the game.
Keep the extracted folder together. Do not move only the executable out of the package; leave the supporting files alongside it.

What you need

The public package does not include the original game. You must provide your own legally obtained disc image. OpenBIOS is supplied as the default BIOS alternative; a retail SCPH-1001 BIOS is optional if you have one and choose to use it.

Updates and saves

Check the Releases page for newer Windows packages and release notes. The Windows updater in supported builds can check the project's Nightly release. The updater is designed to preserve player configuration and save data while replacing shipped application files.

For troubleshooting, report reproducible issues through the project's GitHub Issues page and include relevant build information.
