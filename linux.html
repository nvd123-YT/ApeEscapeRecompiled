Installation

Run the AppImage

  1. Open the GitHub Releases page and download the Linux x86_64 AppImage.
  2. Open a terminal in the directory containing the downloaded file.
  3. Make the file executable with chmod +x ./YourDownloadedFile.AppImage, replacing the example filename with the exact name of your download.
  4. Launch it with ./YourDownloadedFile.AppImage.
  5. In the launcher, select your own Ape Escape disc image, configure your settings, and start the game.
Package note: The published Linux package is an x86_64 AppImage. Check the release notes for any build-specific requirements or known issues before troubleshooting your distribution.

Game data and BIOS

The original game is not included. You must supply your own legally obtained Ape Escape disc image; CUE/BIN and CHD are supported. OpenBIOS is supplied as the default alternative to a retail PlayStation BIOS.

Updates

Linux AppImage updates are currently manual. Download the newer AppImage from GitHub Releases and keep any user data you want to retain. Check the release notes when moving between versions.
