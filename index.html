Before you play

Bring your own game data.

The original game is not included with this project. You will need your own legally obtained Ape Escape disc image. The launcher supports CHD and CUE/BIN formats.

No retail PlayStation BIOS is bundled. OpenBIOS is supplied as the default alternative; a retail BIOS is optional if you have one and choose to use it.
